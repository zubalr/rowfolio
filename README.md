# Rowfolio

Rowfolio is a browser-based spreadsheet briefing tool, designed to connect every finding to its source data.

The planned workflow covers data review and cleanup, deterministic analysis, source-row evidence, cost scenarios, and editable Excel and PowerPoint exports. English and Arabic interfaces are part of the core design.

Processing runs locally in the browser. The application is under development; setup and usage instructions will accompany the implementation.
