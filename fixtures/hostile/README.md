# fixtures/hostile — bounded synthetic adversarial fixtures

Small, generator-produced fixtures that must *fail specific checks* —
the harness's proof that its assertions detect real defects instead of
passing on empty stubs. No private or business workbooks; every binary
artifact is synthesized byte-deterministically by `generate.ts`
(store-only ZIP writer, fixed DOS timestamp → identical output on every
machine).

## Envelope

| Limit | Value |
| --- | --- |
| max file size | 64 KiB |
| max expanded size | 8 MiB |
| max archive entries | 64 |

`manifest.json` carries the envelope and the expected finding codes per
fixture; `tests/helpers/inspect.test.ts` enforces the sizes.

## Layout

- `manifest.json` — fixture inventory: `{path, inspector, expect[], context?/reference?/fields?/oracle?}` plus `meta` (this file, the generator, hash lists).
- `native/` — binary artifacts (`xlsx`, `zip`, `cfb`, `csv`), each with sha256 in `native/MANIFEST.sha256`.
- `worker/` — worker response/progress/envelope JSON wire samples (stale revision/session, old protocol, malformed shape, missing/duplicate/size-mismatched binary slots, progress regression).
- `locale/` — EN reference catalog + AR variants (clean, missing key, placeholder mismatch, extra key).
- `analysis/` — claims copied verbatim from the oracle vs. planted wrong metrics.
- `csv/` — formula-injection, ragged rows, clean control.

`fixtures/hostile/generated/` is reserved for the external bulk worker —
absence is expected, not a gap.

## Regenerate / verify

```bash
node fixtures/hostile/generate.ts           # rewrite native/ artifacts
node fixtures/hostile/generate.ts --verify  # fail if disk != generated bytes
```

Any change to `generate.ts` that alters output is visible in
`native/MANIFEST.sha256` and `tooling/test/corpus-report.json` — explain
the diff in the PR.
