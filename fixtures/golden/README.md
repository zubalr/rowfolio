# fixtures/golden — truth fixtures derived from the independent oracle

Every file here is generated by `tooling/dataset/export_golden.py` from the
independent Decimal oracle (`verify_sample.py`) reading canonical CSV — never
hand-authored. Regenerate after any intentional fixture change and review the
diff.

| File | Contents |
|---|---|
| `oracle_report.json` | Full oracle output: counts, headline truth, all source-row lists, anomaly record. |
| `expected_source_spans.json` | Canonical inclusive `RowSpan`s for the headline evidence selections (North May 1202–1301, North June 1802–1901) plus the East anomaly coordinate. One-based physical rows on sheet `S0`. |
| `fixture_hashes.json` | SHA-256 of every file in `fixtures/sample/`. |

The prepared production snapshot (`apps/web/public/sample/prepared.snapshot.json`)
is intentionally absent until the ingest/normalize/analysis adapters merge; it is
produced only by `tooling/dataset/build_sample_snapshot.mjs` through the real
engine.
